A vault holds recordings the way it holds books: a lecture you taped, a conversation, a voice note. A recording says nothing until a model has listened to it, and the listening happens here, on your machine — nothing is uploaded and no account is involved.

A file is a recording by its name: `.mp3`, `.wav` and `.flac` are the containers numen walks as recordings, plays, and listens to. Anything else in the folder is a file like any other.

## Opening one

A recording opens in a tab of its own: the player at the top, and under it the transcript written as one text.

The time in the gutter beside a line is where that line was said. Press it and the recording plays from there. The line being said is drawn in the accent as it goes, and the button beside the player decides whether the view follows it or stays where you put it.

## Asking for a transcript

Right-click a recording in the [files](/files/) and choose **Transcribe**. With one open, **More** at the end of the player strip offers the same run, and so does **Transcribe this recording** in the [commands](/commands/), under **This file**.

A recording numen holds no transcript for offers the same run in its own tab, under the player, where there would otherwise be words.

The words arrive while the run goes, so a long talk becomes searchable before it is finished.

## Taking turns

A recording is transcribed only when you ask. Recognising a scanned book and transcribing a recording use the same models and the same processor, so they take turns, and a long recording lets other waiting work run between its batches.

## When nothing comes back

A recording with no speech in it gets no transcript. A file the transcriber cannot open stays in the status bar with the reason.

## Editing the words

A transcript is yours to correct. Type into it and it is written back against the recording, the way a note is written back — there is no separate save. A run holding the recording writes over nothing you typed: the words are read-only while it goes.

## Proofreading the transcript

A transcription model can misspell names, confuse homophones, and fail to identify sentence boundaries. A proofreader verifies and corrects these errors without altering original meaning.

**Proofread transcript** is in the **More** menu at the end of the player strip, and **Proofread the transcript of this recording** is in the [commands](/commands/). Pressing it always answers in a sentence — the run has begun, or the transcript has already been put right, or the words were written by hand, or another run holds the recording, or nothing has been transcribed yet.

It is offered where an enabled plugin proofreads timed text. The proofread transcript is a new version beside the one it was made from, and deleting it brings that one back.

## Deleting the transcript

**Delete transcript** is in the same **More** menu, and in the commands. It deletes the transcript shown. Deleting an edit or a proofread version brings back the version it was made from; deleting the transcription leaves the recording untranscribed. It asks first.

## Where it is kept

The transcript is a [WebVTT](https://developer.mozilla.org/en-US/docs/Web/API/WebVTT_API) file in the transcription plugin's folder, `.numen/md.numen.engines.transcription/`, named after the bytes of the recording. Move or rename the recording and its transcript follows it; keep two copies of one recording and they share it.

WebVTT is somebody else's format, which is the whole of its appeal: it opens in a player, it renders as subtitles in a browser, and it is still useful if you take it somewhere numen has never been.

## From a terminal

The [command line](/cli/) does the same run without a window, which is what you want for a folder you would rather leave going overnight:

```sh
numen-cli transcribe Research "Lectures/Lecture 4.mp3"
```


## Finding a moment

A recording answers searches like anything else, and a result opens it at the second the words were said rather than at the top. Ask the [agent](/agent/) about a lecture and it reads the transcript, quotes it into a note, and can put the moment in front of you.

Everything here is `transcription` in [the settings file](/settings/). The complete list is on [every setting](/reference/).
