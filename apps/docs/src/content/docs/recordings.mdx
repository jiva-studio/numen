A vault holds recordings the way it holds books: a lecture you taped, a conversation, a voice note. A recording has no text until a model has transcribed it, and the transcription runs here on your machine. Nothing is uploaded and no account is involved.

A file is a recording by its name: `.mp3`, `.wav` and `.flac` are the formats numen treats as recordings, plays and transcribes. Anything else in the folder is a file like any other.

## Opening one

A recording opens in a tab of its own: the player at the top, and under it the transcript written as one text.

The time in the gutter beside a line is when that line was spoken. Click it and the recording plays from there. The line being spoken is highlighted in the accent colour as the recording plays, and the button beside the player sets whether the view follows it or stays where you put it.

## Asking for a transcript

Open a recording numen holds no transcript for, and its tab offers **Transcribe** under the player, where there would otherwise be words. **Recognise the text with Audio/Video Transcription** in the [commands](/commands/), under **File**, does the same for the open recording.

The words appear while the run is in progress, so a long talk becomes searchable before it is finished.

## Sharing the processor

A recording is transcribed only when you ask. Recognising a scanned book and transcribing a recording use the same models and the same processor, so they run in turn, and a long recording lets other waiting work run between its batches.

## When there is no result

A recording with no speech in it gets no transcript. A file the transcriber cannot open stays in the status bar with the reason.

## Editing the words

You can correct a transcript. Type into it and the change is saved with the recording, the way a note is saved, with no separate save. While a run is using the recording, the words are read-only, so the run never overwrites what you typed.

## Proofreading the transcript

A transcription model can misspell names, confuse homophones, and fail to identify sentence boundaries. A proofreader verifies and corrects these errors without altering original meaning.

**Proofread transcript** is in the **More** menu at the end of the player strip, and **Proofread the text with LLM Proofreading** is in the [commands](/commands/). Pressing it always shows a one-sentence message: the run has started, or the transcript is already corrected, or the words were written by hand, or another run is using the recording, or nothing has been transcribed yet.

It is offered where an enabled plugin proofreads timed text. The proofread transcript is a new version next to the one it was made from, and deleting it brings that one back.

## Deleting the transcript

**Delete transcript** is in the same **More** menu, and in the commands as **Delete the text Audio/Video Transcription made**. It deletes the transcript shown. Deleting an edit or a proofread version brings back the version it was made from; deleting the transcription leaves the recording untranscribed. It asks for confirmation first.

## Where it is kept

The transcript is a [WebVTT](https://developer.mozilla.org/en-US/docs/Web/API/WebVTT_API) file in the transcription plugin's folder, `.numen/md.numen.engines.transcription/`, named after the bytes of the recording. Move or rename the recording and its transcript follows it; keep two copies of one recording and they share it.

WebVTT is an existing standard format, which is its main advantage: it opens in a player, it renders as subtitles in a browser, and it is still useful outside numen.

## From a terminal

The [command line](/cli/) does the same run without a window, which suits a large folder you want to leave running overnight:

```sh
numen-cli transcript.create Research "Lectures/Lecture 4.mp3"
```

## Finding a moment

A recording appears in search results like anything else, and a result opens it at the second the words were spoken rather than at the start. Ask the [agent](/agent/) about a lecture and it reads the transcript, quotes it into a note, and can show you the moment.

The transcription's settings are the Audio/Video Transcription plugin's own, on its page in the [settings](/settings/): the model it transcribes with. Parakeet v3, the default, detects which of 25 European languages is spoken; Parakeet v2 transcribes English.
