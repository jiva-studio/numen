## What ships

`numen` is built into the application: this product's own palette, light and dark. The other
twelve come with the **Preset Themes** plugin, and the list shows them under that name. If you
turn the plugin off in the settings, they are removed from the list, and a window using one switches back to
`numen`.

|                                                              |                                                 |
| ------------------------------------------------------------ | ----------------------------------------------- |
| `catppuccin`                                                 | Latte in the light, Mocha in the dark.          |
| `github`                                                     | Light Default and Dark Default.                 |
| `gruvbox`                                                    | light and dark, orange the accent.              |
| `solarized`                                                  | light and dark, one set of accents across both. |
| `ayu`                                                        | light and dark, yellow the accent.              |
| `tokyo-night`                                                | Tokyo Night, and Tokyo Night Light.             |
| `dracula`, `nord`, `one-dark`, `monokai`, `cobalt2`, `amber` | dark only.                                      |

A palette published in one half only fixes that half, and **Light or dark** has no choice
while it is applied.

## Writing your own

A theme is one CSS file that sets the colours the interface uses. Every token you
leave out keeps the value it already had, so a file naming a single colour is a theme.

Put it in `themes/` inside [the folder numen keeps its own things
in](/install/#where-numen-keeps-its-own-files) — beside `numen.json`. The folder is created
on the first run.

```css
:root {
  --numen-surface: #101014;
  --numen-raised: #17171d;
  --numen-ink: #e6e6ea;
}
```

`dracula.css` in that folder appears in the list as **your** dracula, beside the one the plugin
adds; neither hides the other. Save the file and the window applies the change on the next reload —
the folder is watched.

A few rules:

|              |                                                                                     |
| ------------ | ----------------------------------------------------------------------------------- |
| One level    | a folder inside `themes/` is not a theme, and neither is a file inside that folder. |
| `.css`       | `dracula.css.bak` and `README.md` are files in a folder, not themes.                |
| Under 256 KB | every shipped palette is under two kilobytes.                                       |

### Light and dark in one file

Write both halves as pairs, and **Light or dark** chooses which is read:

```css
:root {
  --numen-surface: light-dark(#fdf6e3, #002b36);
}
```

Or define one half only, with flat colours, and declare which half it is:

```css
:root {
  color-scheme: dark;
  --numen-surface: #21222c;
}
```

## The colours a theme can set

**The window**

|                      |                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| `--numen-surface`    | the background colour of the window.                                                             |
| `--numen-raised`     | the fill of a node, a card and a pane.                                                           |
| `--numen-ink`        | text on that fill, and the caret in it.                                                          |
| `--numen-rule`       | the border line around it.                                                                       |
| `--numen-accent`     | the node the keyboard is on, the fill of a button, and every line and mark in the accent colour. |
| `--numen-accent-ink` | text on the accent.                                                                              |
| `--numen-ring`       | the outline around what is focused, and a link in marked-up text.                                |
| `--numen-alarm`      | what is wrong: a refusal, and what could not be read.                                            |
| `--numen-alarm-bg`   | the background of a card that shows one of those.                                                |
| `--numen-hushed`     | secondary text next to what it describes: a caption, a count, a month over a grid.               |

**The plex**

|                              |                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `--numen-relation-parent`    | the colour of a parent relation.                                                     |
| `--numen-relation-child`     | a child's relation.                                                                  |
| `--numen-relation-jump`      | a jump's relation.                                                                   |
| `--numen-relation-reference` | a reference's relation.                                                              |
| `--numen-relation-sibling`   | a sibling's relation.                                                                |
| `--numen-edge`               | the line drawn between two nodes.                                                    |
| `--numen-edge-label`         | the words on that line, which follow `--numen-hushed` unless a theme says otherwise. |

**Text being read, and text about to change**

|                           |                                                                          |
| ------------------------- | ------------------------------------------------------------------------ |
| `--numen-selection`       | the background of selected text.                                         |
| `--numen-selection-away`  | the same selection where the keyboard is elsewhere.                      |
| `--numen-selection-match` | every other place where that text appears.                               |
| `--numen-highlight`       | the background of a range of text that is about to change.               |
| `--numen-caution-bg`      | the background of a message you should read but need not act on at once. |
| `--numen-caution-fg`      | the text in that message.                                                |
| `--numen-positive`        | the colour of work that is going well and is still in progress.          |

**Marked-up text**

|                              |                                                  |
| ---------------------------- | ------------------------------------------------ |
| `--numen-syntax-mark`        | the markdown marks, shown under the caret.       |
| `--numen-code-bg`            | the background of code.                          |
| `--numen-table-head-bg`      | the background of the head row of a table.       |
| `--numen-syntax-keyword`     | keywords, modifiers, operators written as words. |
| `--numen-syntax-name`        | variables, properties, attributes.               |
| `--numen-syntax-type`        | type names, class names, namespaces, tags.       |
| `--numen-syntax-string`      | strings and regular expressions.                 |
| `--numen-syntax-number`      | numbers, booleans, atoms, escapes.               |
| `--numen-syntax-comment`     | comments, which are set in italic.               |
| `--numen-syntax-punctuation` | operators, brackets, separators.                 |

**What appears over the window**

|                        |                                                                     |
| ---------------------- | ------------------------------------------------------------------- |
| `--numen-panel-bg`     | the tint of a panel.                                                |
| `--numen-panel-border` | the line around it.                                                 |
| `--numen-panel-blur`   | a length: how much the content showing through the tint is blurred. |
| `--numen-panel-shadow` | the shadow of a panel, including offsets and spread.                |
| `--numen-shadow-card`  | the shadow of a card, written the same way.                         |
| `--numen-scrim`        | the overlay colour a panel puts over what it covers.                |

**Text fields and messages**

|                        |                                       |
| ---------------------- | ------------------------------------- |
| `--numen-field-bg`     | the background of a text field.       |
| `--numen-field-border` | the line around it.                   |
| `--numen-bubble-bg`    | the bubble around what you wrote.     |
| `--numen-bubble-fg`    | the words in it.                      |
| `--numen-answer-fg`    | the reply text, shown on the surface. |

## What a theme leaves alone

The type and the measures: the font stack, the text sizes, the line height, the radii, the
clearances, the durations. They are the same under every palette, so a theme changes the colour
of the window and never its layout.

The two sizes you choose — interface and reading — are set by you, and a theme cannot override them.

## Themes from a plugin

A plugin adds themes by listing them in its `manifest.json`, each with the CSS file that holds it.
A theme plugin needs no code, only the manifest and the stylesheets.

```json
{
  "contributes": {
    "themes": [{ "id": "night", "name": "Night", "appearance": "dark", "file": "themes/night.css" }]
  }
}
```

`appearance` is `light` or `dark` for a palette published in one half, and left out for a palette
in two halves. `file` must be inside the plugin's folder and is a `.css` file under 256 KB.
