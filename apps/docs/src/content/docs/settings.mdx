**Settings** in the commands opens the settings page, which edits the settings file. It lists **System**, the settings of the window itself, and below it every installed plugin, each with a page of its own. The search at the top narrows the list by a plugin's name, its description or its kind. The rest of the file is edited in any text editor, see [the file](#the-file).

Changing a control saves it. There is no separate save, and nothing is applied later: a theme chosen here is applied immediately.

## System

At the top of **System** is the path of the file that the page edits. See [the file](#the-file).

### The window

|                    |                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| **Theme**          | the stylesheet the window applies, in two origins: the ones that ship with numen, and yours. See [themes](/themes/).            |
| **Light or dark**  | follow the system, or choose one. A theme that declares light and dark itself gives no choice here, and the control shows that. |
| **Interface size** | how large the chrome, the controls and the type in them are. 1 is as designed.                                                  |
| **Reading size**   | how large the text you read is, on top of the size above.                                                                       |

The two sizes are multipliers over what was designed. The interface goes from **0.8 to 2** and the text you read from **0.8 to 1.75**; hairlines, borders and focus rings stay one physical line wide at either size. A number outside those bounds is rejected, reported with an alert, and left in the file exactly as you wrote it.

### What a note is called

**Sync title and filename** says whether renaming a note renames its file, and the other way round.

## A plugin's page

A plugin's page holds what the plugin declares, and the window's controls over the plugin itself:

|                          |                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **Enabled**              | whether the plugin runs at all. A disabled plugin offers none of its commands, views or texts.  |
| **Plugins that stopped** | a plugin the window could not start, with when it failed and why, and **Retry** or **Disable**. |

Below them are the plugin's own settings, each with the control its manifest declares — a model to choose, a number, a list. The [scanned books](/reader/) and [recordings](/recordings/) pages say which of those are worth changing.

## In the commands

Some of the same settings are in the commands as well — <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd>, under **General**: **Theme**, **Light or dark**, **Interface size**, **Reading size**, **Sync title and filename**, **Performance profile**. A plugin can offer one of its settings there too, named after the plugin.

A row on the page and the command of the same name use the same code, so it makes no difference which you use.

## The file

Every setting is in one file, `numen.json`, in [the folder numen keeps its own things in](/install/#where-numen-keeps-its-own-files). The settings page shows its path at the head of **System**.

It is yours to edit. Fields you leave out keep their defaults, so a file naming one setting is a
complete file. Keys numen does not know are kept unchanged, and a file that does not
parse is never overwritten: numen reports the error and does not change the file.

```json
{
  "app": {
    "appearance": {
      "mode": "system",
      "theme": "preset:numen",
      "interfaceScale": 1,
      "textScale": 1
    }
  }
}
```

## What is in it

|                   |                                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| `app.appearance`  | how the window is drawn: the theme, which half of it and the two sizes.                               |
| `app.naming`      | whether a note's title and its filename are kept as one name. See [writing notes](/editor/#renaming). |
| `app.performance` | how much of the machine the background work may use.                                                  |
| `<plugin id>`     | each plugin's own settings, in an object named by its id.                                             |

[Every setting](/reference/) is the complete list, generated from the application itself.

A key to a service is never in this file: it is entered with the connection, in the app,
and stored in your system's keychain.
