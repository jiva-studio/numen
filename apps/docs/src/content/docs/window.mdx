## What a tab can hold

|              |                                                                                         |
| ------------ | --------------------------------------------------------------------------------------- |
| A note       | the prose, [saving as you type](/editor/).                                              |
| A plex       | the map of what a note is connected to.                                                 |
| An agent     | a conversation about the vault.                                                         |
| A document   | a book or a PDF, [read in place](/documents/).                                          |
| A recording  | the player above [the transcript](/recordings/).                                        |
| A deck       | [the cards](/cards/) of one file, as a grid under their sections.                       |
| A card model | the fields a card has, and [the templates](/cards/#a-card-model) that use them.         |
| A preset     | [how much work a day of review contains](/review/#a-preset), and the curve of its goal. |
| The files    | [the folders of the vault](/files/) as they are on disk.                                |
| The settings | [what this installation is configured as](/settings/), a control to a setting.          |
| `numen.json` | [the settings file itself](/settings/#the-file), to edit by hand.                       |

A note, a plex and an agent open as many times as you like: two notes side by side, two plexes showing different notes, a second agent working on something else. A file that is not a note opens once, in the tab it is already in. The files, the settings and the settings file are limited to one per window, because there is only one of each.

The kinds that hold a file — a note, a document, a recording, a deck, a card model, a preset — are chosen by opening the file, not by choosing a kind. numen opens each file in the editor for its type, and a file whose type it does not know is opened as a note.

## When nothing is open

Close the last tab and the window does not go blank: it shows the ways to start, each with its shortcut: search the vault, show the commands, a new note, a plex, an agent, the
settings. Under them are the vaults this installation has. The vault you are in is labelled as such; a vault
whose folder is missing is labelled that way instead.

A window with no vault open offers the settings, that list, and **Create vault**. A plex and an agent each need a vault, and the settings belong to the installation, not to a vault.

## Panes

Drag a tab to the edge of a pane to split it — left, right, top or bottom, whichever edge is
nearest. Drag it into the middle of another pane to join that stack instead. The handle
between two panes moves the boundary.

**Open note beside** in the commands does the same without the dragging: it puts what you chose in a
pane next to the one you are in.

<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>W</kbd> closes the current tab. A tab with an
unresolved choice shows a warning the first time and closes the second time you ask.

## Linked tabs across panes

Tabs in separate panes can be linked together to synchronize the active note across views.

Right-click any Note, Plex, or Files tab header to open the link menu:

- Pick an open tab from another pane to link them into a group.
- Linked tabs display a matching colored link indicator in their headers.
- Navigating to a note in a note editor updates linked Plex graphs to focus that note and selects it in linked file trees.
- Selecting a node in a linked Plex or a file in a linked Files tab opens that note in the linked editor pane.
- Right-click and choose **Unlink** to detach a tab from its group.

## The two keys everything starts from

<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>K</kbd> searches the vault. <kbd>Ctrl</kbd>/<kbd>⌘</kbd>
<kbd>P</kbd> opens the commands — everything the window can do, for the note you are on, for the
file, for the window and for the vault. Both are in the same panel and each closes the other.

Commands are grouped by what they act on:

- **Note** — show it in the plex, make a child, change the title, ask the agent about it,
  copy its path, remove it.
- **File** — transcribe a recording, proofread its transcript, read the text of a scan.
- **General** — a new note, a new agent, close this tab, search, appearance, the settings.
- **Vault** — go to a note, open or make a vault, rename, remove, erase.

A command that cannot act on the open tab shows why rather than disappearing: with a
document open, _nothing in front of you is a note_; during the first scan, _the vault is still
being read_.

The [keyboard page](/keyboard/) lists what has its own key.

## Background tasks

The title bar shows what is running in the background: vault scanning, vector embedding, document OCR, and audio transcription progress. It says **Ready** while nothing runs, or how many tasks are active, with a badge for the ones that failed. A click on it opens the list of the tasks with their progress and errors; a running task can be cancelled there, and a failure or a notice taken out of the list. The Tasks plugin draws it; turned off, no task status is shown.

A bar at the bottom of the window comes from the Status bar plugin, which is off by default. It shows the commands and views other plugins place in it, and without the plugin there is no bar.

The list of tasks is also where the window reports overall vault status — _not following the vault_, _the vault could not be read_. See [when something is wrong](/trouble/).
