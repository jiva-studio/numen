Two keys open everything else: <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>K</kbd> searches the vault, and <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the [commands](/commands/). Each closes the other, and <kbd>Escape</kbd> closes either.

Everywhere below, <kbd>Ctrl</kbd> and <kbd>⌘</kbd> are the same key: whichever your keyboard has.

## Commands with a key of their own

A command gets a key if it is used often and leaves nothing to undo. No command that removes a note, a vault or a file is ever a single keystroke.

Every other command is on the [commands page](/commands/) and is available by name.

## In the search and the commands

| | |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | move through the list. |
| <kbd>Home</kbd> <kbd>End</kbd> | the first and the last of it. |
| <kbd>Enter</kbd> | choose the highlighted item. |
| <kbd>Backspace</kbd> in an empty field | go back: out of a command that is prompting for input, and back to the search. |
| <kbd>Escape</kbd> | one step back, and close the panel at the last of them. |
| <kbd>Tab</kbd> | nothing. The panel captures it, so keyboard focus cannot leave the panel. |

## In the plex

| | |
| --- | --- |
| <kbd>Tab</kbd> | move focus to the map, and from node to node. |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | go to the node the keyboard is on: it becomes the middle. |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | open that note in a tab. |
| <kbd>Alt</kbd> <kbd>⇧</kbd> <kbd>Enter</kbd> | open it in a pane beside this one. |
| <kbd>⇧</kbd> <kbd>F10</kbd>, or the menu key | the node's menu, with the commands for that note. |
| <kbd>Enter</kbd> on a node's handle | add one more child to that node. To create the new note elsewhere, drag the handle. |
| <kbd>Escape</kbd> | cancel a connection you are drawing. |

## In a menu

| | |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | move through it. |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | the same, forwards and back. |
| <kbd>Home</kbd> <kbd>End</kbd> | the first and the last item. |
| <kbd>Enter</kbd> | choose. |
| <kbd>Escape</kbd> | close it, and keyboard focus returns to where it was. |

## In a note

Saving is automatic, and everything else is the editing you already know.

| | |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>S</kbd> | save now, instead of [waiting about a second](/editor/) for the automatic save. |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | undo. |
| <kbd>Ctrl</kbd> <kbd>Y</kbd>, or <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> on a mac | redo. |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | indent the line, and remove the indent. |
| <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | move the line up or down. |
| <kbd>⇧</kbd> <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | copy the line up or down. |
| <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | add another caret on the line above or below. |
| <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>K</kbd> | delete the line. |
| <kbd>Ctrl</kbd> <kbd>Enter</kbd> | open a blank line below, wherever the caret is on this one. |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | select the whole note. |
| <kbd>Ctrl</kbd> <kbd>Home</kbd> / <kbd>Ctrl</kbd> <kbd>End</kbd> | the top and the bottom of the note. |
| <kbd>Escape</kbd> | remove every caret but one. |

## In a table

A table in a note is shown as a table, not as pipes and dashes: you put the caret in a cell and type.

| | |
| --- | --- |
| <kbd>Tab</kbd> | the next cell. On the last one, a new row. |
| <kbd>⇧</kbd> <kbd>Tab</kbd> | the cell before. |
| <kbd>Enter</kbd> | the cell below. |
| <kbd>Escape</kbd> | leave the table and return to the text under it. |

## In the agent

| | |
| --- | --- |
| <kbd>Enter</kbd> | send. |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | a new line in what you are writing. |

## Between tabs

| | |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> on the tab strip | move along it. |
| <kbd>Escape</kbd> | leave the tab's content and return to the tab itself. |
| <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>W</kbd> | close the current tab. |
