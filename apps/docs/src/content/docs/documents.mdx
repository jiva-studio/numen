A vault holds more than notes. PDFs and EPUBs in the folder are read as documents: their
text is searched along with everything else, and a result opens the book at the page that contains the words.

## Reading a PDF

Open a document in a tab as you would a note. It opens at the page a search sent you to, and the
passage that matched is highlighted at its place on the page.

Page numbers are positions in the file.

The controls are shown over the page and take no space in the window. They are: back and forward a page, the number of the page you are on (type another number and press <kbd>Enter</kbd> to go there), and zoom in and out. The page starts at the size that fits the available space, each press enlarges it by a quarter, and six times that is the largest zoom.

## Reading an EPUB

An EPUB has no pages of its own. It is laid out again in the pane you read it in: one column where the pane is narrow, two where it is wide. You turn a page at a time by the arrow keys, by a swipe, or by pressing near either edge. It is never scrolled.

The book uses numen's own typography and the theme you are reading in. The two size buttons change the text size rather than magnifying an image. A larger size lays out the columns again, and the place you were reading stays in view. Your position in a book is a place in its text, not a page number, so it is kept when the pane or the text size changes.

The contents show the table of contents that the book defines. Many books define none. For those, the contents list the pages of the printed edition the book was set from, or else the book's own chapters as the file has them, so there is always somewhere to jump to.

Where a book contains the page breaks of the printed edition it was set from, they are shown as that edition's page numbers. They belong to the printed book and are separate from the count of pages the window shows, which changes with the size of the pane and the text.

Two kinds of EPUB are not read. One whose text is locked by DRM is rejected rather than indexed as unreadable text. A book whose fonts alone are obfuscated is read normally. One laid out as fixed pages, like a comic or a picture book, shows a message instead of being reflowed into unreadable text.

## Scanned books

A book that is scans of paper has no text to read. The Document OCR plugin reads its pages
on your machine automatically once the book is in the vault: nothing is uploaded, no
account is involved.

**Recognise the text with Document OCR** in the [commands](/commands/), under **File**, starts it
on the book you have open, and so does asking the [agent](/agent/) to read it. How the text is read is described in [scanned books](/reader/).

It runs behind the window and shows its progress in the title bar. The book appears in search results once
every page is read. A run that stops part way continues where it stopped.

The result is stored in the OCR plugin's folder inside the vault's own `.numen/` folder,
`.numen/md.numen.engines.ocr/`, one file per document.

## Quoting into a note

The agent can read a run of a document's text and write it into a note. It can also show you a
passage: the document opens at that page, at the words in question.
