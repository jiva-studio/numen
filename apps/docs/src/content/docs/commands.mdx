<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the commands. Type to narrow the list, <kbd>↑</kbd>
<kbd>↓</kbd> to walk it, <kbd>Enter</kbd> to run what is highlighted.

The same list is on a node in the [plex](/plex/): right-click one, or press <kbd>⇧</kbd>
<kbd>F10</kbd> on it, and what you get is the commands over that note.

## What a command asks for

A command that needs something asks for it in the same panel, one step at a time — a name to
call a note, a note to go to, a vault to open, a value to choose. <kbd>Backspace</kbd> in the
empty field steps back, <kbd>Escape</kbd> leaves.

Some ask you to confirm rather than to type: removing a vault says the folder stays. Destroying a
note and erasing a vault make you type the name first.

The bands say what a command acts on: **Note**, the note in front of you; **File** — the texts a
plugin makes of the file in front of you, and the commands a plugin offers over its type;
**General**, the window; and **Vault**.

Over a file, a command names the plugin that does it: each plugin that reads the file's type
offers to recognise its text, each that reads the text offers to proofread it, and each text a
plugin made can be deleted. A link (`.url`) also offers the Media Importer's commands: download
the text again, download a copy to play from this disk, and delete that copy.

A command that cannot act on what is in front of you stays on the list and says why —
_nothing in front of you is a note_, _the vault is still being read_ — rather than quietly
disappearing.
