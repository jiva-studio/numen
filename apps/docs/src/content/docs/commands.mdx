<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the commands. Type to narrow the list, <kbd>↑</kbd>
<kbd>↓</kbd> to move through it, <kbd>Enter</kbd> to run the highlighted command.

The same list is on a node in the [plex](/plex/): right-click one, or press <kbd>⇧</kbd>
<kbd>F10</kbd> on it, and you get the commands for that note.

## What a command prompts for

A command that needs input prompts for it in the same panel, one step at a time: a name for a note, a note to go to, a vault to open, a value to choose. <kbd>Backspace</kbd> in the
empty field steps back, <kbd>Escape</kbd> leaves.

Some ask you to confirm rather than to type: removing a vault tells you the folder stays, and emptying
the trash tells you it cannot be undone. Erasing a vault makes you type its name first.

The bands show what a command acts on: **Note**, the open note; **File**, the texts a
plugin creates from the open file and the commands a plugin offers for its type;
**General**, the window; and **Vault**.

For a file, a command shows the plugin that runs it: each plugin that reads the file's type
offers to recognise its text, each that reads the text offers to proofread it, and each text a
plugin created can be deleted. A link (`.url`) also offers the Media Importer's commands: download
the text again, download a copy to play from this disk, and delete that copy.

A command that cannot act on the open tab stays on the list and shows why (_nothing in front of you is a note_, _the vault is still being read_) instead of disappearing.

## Every command
