The panel along the edge of the window is an agent that works inside your vault. It searches
your notes, reads them, writes them, and connects them — the same operations you have, which you start
by asking in words.

## Asking

Type into the panel and send. **Ask agent about note** in the commands starts a
conversation about the note you are on, and <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>⇧</kbd>

<kbd>A</kbd> opens a fresh one.

It is told which note you are looking at, so _this note_, _file this under Thermodynamics_ and
_what did I write about entropy_ all mean what you would expect them to mean.

Each step is shown as it happens (the note it read, the link it added), and **Stop**
ends the run at once.

## What it can do

|           |                                                                                                                                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Notes     | search the vault, read notes, write and edit them, rename, move, remove, and open one for you.                                                                                                           |
| Links     | add, change, remove and list the links a note contains.                                                                                                                                                  |
| Documents | list the books and recordings a vault holds, read a stretch of one, start the reading of a scan or the transcription of a recording, show you a passage.                                                 |
| Cards     | read a [deck](/cards/) and the card models a vault has, add a card, edit one, remove one, open a section, make a deck or a card model, rename a field across a card model and in everything based on it. |
| Files     | read a stretch of any other file the vault contains, by its path — a transcript somebody typed, an export, whatever you put in the folder.                                                               |
| Vaults    | tell you what could not be read from a scan, and list, add, rename, remove and open vaults.                                                                                                              |

It is also told what you have open — every tab of the window and which of them you are looking at — because you move between tabs while it works.

It has web search and web fetch as well, for the questions your notes do not answer.

Anything it writes is saved in your files, so it appears in the plex and in search at once. An agent that creates a note can find it by searching.

A note it names in its answer is a link you can click. It opens in a tab beside the conversation. See [following a link](/links/#following-a-link).

## What it cannot do

**It has no shell.** It accesses your vault only through the operations above. It cannot run a command on your machine, and the one tool that reads a file by its path reads only inside the vault folder. A path outside it, or to a file the vault skips, is rejected.

**It does not read instructions stored in the vault.** A vault is a folder that can come from
another place (synced, cloned, shared or restored), and a configuration file inside one can list
commands for your machine to run. Those are always rejected, whatever the settings say.

**It cannot erase a vault from your disk.** Removing a folder from the list needs your confirmation. Adding a folder to the list it can do when you ask: nothing already in the folder is moved or rewritten, and the vault's identity is written into the folder so it is recognised after it is moved.

By default it also ignores what is configured for the assistant on this machine — standing
instructions, hooks, skills, plugins. If you want your own configuration used, turn on
`reads_hooks_and_skills` in the settings of the Claude Code Agent plugin (the object `md.numen.agents.claude`, see [the settings](/settings/)); a vault's own files are
rejected either way.

## Setting it up

numen auto-discovers installed CLI agents on your machine — checking standard paths and installers for Claude Code and compatible tools. The floating selector island above the message composer lets you pick which discovered agent or model is used for the active conversation.

Where an agent is installed in the usual place, numen finds it automatically and there is nothing to configure.

```json
{
  "app": {
    "agent": {
      "use": "claude",
      "claude": {
        "command": [],
        "model": ""
      }
    }
  },
  "md.numen.agents.claude": {
    "reads_hooks_and_skills": false
  }
}
```

|           |                                                                                                                             |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| `use`     | which agent is used. Empty means none, and the panel says so.                                                               |
| `command` | how to start it. Empty looks on the path, then where its installers put it. Set it on a machine with several installations. |
| `model`   | `opus`, `sonnet`, or a full model name. Empty uses that installation's default model.                                       |

`reads_hooks_and_skills` is a setting of the Claude Code Agent plugin, off by default, as described above.

## Another agent, in another window

The panel is not the only way to reach the vault. While the window is open, the Model Context Protocol Server plugin serves the same tools over MCP
on this machine, so an assistant you already use elsewhere can work in the vault too — see
[connect another agent](/connect/).

## Where it runs, and what it costs

The agent runs on your machine and uses your own account with the model provider. numen has no server, and there is nothing for your notes to be uploaded to: the only data that leaves
the machine is what the program you installed and signed in to sends to the model.

[Searching by meaning](/search/) is separate from this, and by default it runs a small model
locally with no account at all.
