# Media Player Plugin

Modular audio player and microphone voice recorder plugin for Numen.

## Features

- **Audio Playback**: Plays `.mp3`, `.m4a`, `.wav`, `.ogg`, and `.aac` audio files.
- **Waveform Visualization**: Interactive 64-bar waveform display with direct click/scrub seeking.
- **Speed Control**: Variable playback rates (0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x).
- **Transcript Synchronization**: Interactive timestamp cues to jump directly to transcribed dialogue.
- **Microphone Recording**: Built-in voice recorder with live audio level meter, recording timer, audio playback preview, and vault export.
