<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the commands. Type to narrow the list, <kbd>↑</kbd>
<kbd>↓</kbd> to walk it, <kbd>Enter</kbd> to run what is highlighted.

The same list is on a node in the [plex](/plex/): right-click one, or press <kbd>⇧</kbd>
<kbd>F10</kbd> on it, and what you get is the commands over that note.

## What a command asks for

A command that needs something asks for it in the same panel, one step at a time — a name to
call a note, a note to go to, a vault to open, a value to choose. <kbd>Backspace</kbd> in the
empty field steps back, <kbd>Escape</kbd> leaves.

Some ask you to confirm rather than to type: forgetting a vault says the folder stays, deleting
the transcript of a recording says the words go and it can be transcribed again. Destroying a
note and erasing a vault make you type the name first.

The bands say what a command acts on: **this note**, **this file** — the runs a recording or a
scan carries — **this window**, and **this vault**.

A command that cannot act on what is in front of you stays on the list and says why —
*nothing in front of you is a note*, *the vault is still being read* — rather than quietly
disappearing.
