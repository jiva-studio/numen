Two keys open everything else: <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>K</kbd> searches the vault, and
<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the commands. Each closes the other, and
<kbd>Escape</kbd> puts either away.

## Commands with a key of their own

A command earns a key by being reached often and by leaving nothing behind you would have to
undo. Nothing that removes a note, a vault or a file is ever one keystroke away.

## In the search and the commands

| | |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | walk the list. |
| <kbd>Home</kbd> <kbd>End</kbd> | the first and the last of it. |
| <kbd>Enter</kbd> | take what is highlighted. |
| <kbd>Backspace</kbd> in an empty field | step back — out of a command that is asking for something, and back to the search. |
| <kbd>Escape</kbd> | one step back, and the panel itself at the last of them. |

## In the plex

| | |
| --- | --- |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | go to the node the keyboard is on. |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | open that note in a tab. |
| <kbd>Alt</kbd> <kbd>⇧</kbd> <kbd>Enter</kbd> | open it in a pane beside this one. |
| <kbd>⇧</kbd> <kbd>F10</kbd>, or the menu key | the node's menu. |
| <kbd>Escape</kbd> | call off a connection you are in the middle of drawing. |

## In a note

| | |
| --- | --- |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>S</kbd> | write now, rather than [waiting the second](/writing/) it would take on its own. |

## Between tabs

| | |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> on the tab strip | move along it. |
| <kbd>Escape</kbd> | out of what a tab holds, back to the tab itself. |
