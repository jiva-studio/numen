Two keys open everything else: <kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>K</kbd> searches the vault, and
<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>P</kbd> opens the [commands](/commands/). Each closes the
other, and <kbd>Escape</kbd> puts either away.

Everywhere below, <kbd>Ctrl</kbd> and <kbd>⌘</kbd> are the same key: whichever your keyboard has.

## Commands with a key of their own

A command earns a key by being reached often and by leaving nothing behind you would have to
undo. Nothing that removes a note, a vault or a file is ever one keystroke away.

Every other command is on the [commands page](/commands/), reached by name.

## In the search and the commands

| | |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | walk the list. |
| <kbd>Home</kbd> <kbd>End</kbd> | the first and the last of it. |
| <kbd>Enter</kbd> | take what is highlighted. |
| <kbd>Backspace</kbd> in an empty field | step back — out of a command that is asking for something, and back to the search. |
| <kbd>Escape</kbd> | one step back, and the panel itself at the last of them. |
| <kbd>Tab</kbd> | nothing. The panel keeps it, so the keyboard cannot wander out of what it is asking. |

## In the plex

| | |
| --- | --- |
| <kbd>Tab</kbd> | onto the map, and from node to node. |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | go to the node the keyboard is on: it becomes the middle. |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | open that note in a tab. |
| <kbd>Alt</kbd> <kbd>⇧</kbd> <kbd>Enter</kbd> | open it in a pane beside this one. |
| <kbd>⇧</kbd> <kbd>F10</kbd>, or the menu key | the node's menu — the commands over that note. |
| <kbd>Enter</kbd> on a node's handle | one more child of that node. Dragging the handle is what puts the new note somewhere else. |
| <kbd>Escape</kbd> | call off a connection you are in the middle of drawing. |

## In a menu

| | |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | walk it. |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | the same, forwards and back. |
| <kbd>Home</kbd> <kbd>End</kbd> | the first and the last item. |
| <kbd>Enter</kbd> | choose. |
| <kbd>Escape</kbd> | leave it, and the keyboard goes back where it came from. |

## In a note

Saving is unasked, and everything else is the editing you already know.

| | |
| --- | --- |
| <kbd>Ctrl</kbd> <kbd>S</kbd> | write now, rather than [waiting the second](/writing/) it would take on its own. |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | undo. |
| <kbd>Ctrl</kbd> <kbd>Y</kbd>, or <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> on a mac | redo. |
| <kbd>Tab</kbd> / <kbd>⇧</kbd> <kbd>Tab</kbd> | indent the line, and take the indent back. |
| <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | move the line up or down. |
| <kbd>⇧</kbd> <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | copy the line up or down. |
| <kbd>Ctrl</kbd> <kbd>Alt</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | put another caret on the line above or below. |
| <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>K</kbd> | delete the line. |
| <kbd>Ctrl</kbd> <kbd>Enter</kbd> | open a blank line below, wherever the caret is on this one. |
| <kbd>Ctrl</kbd> <kbd>A</kbd> | select the whole note. |
| <kbd>Ctrl</kbd> <kbd>Home</kbd> / <kbd>Ctrl</kbd> <kbd>End</kbd> | the top and the bottom of the note. |
| <kbd>Escape</kbd> | drop every caret but one. |

## In a table

A table in a note is a table, not pipes and dashes: the caret goes into a cell and you type.

| | |
| --- | --- |
| <kbd>Tab</kbd> | the next cell. On the last one, a new row. |
| <kbd>⇧</kbd> <kbd>Tab</kbd> | the cell before. |
| <kbd>Enter</kbd> | the cell below. |
| <kbd>Escape</kbd> | leave the table, back into the text under it. |

## In the agent

| | |
| --- | --- |
| <kbd>Enter</kbd> | send. |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | a new line in what you are writing. |

## Between tabs

| | |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> on the tab strip | move along it. |
| <kbd>Escape</kbd> | out of what a tab holds, back to the tab itself. |
| <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>W</kbd> | close the tab in front of you. |
