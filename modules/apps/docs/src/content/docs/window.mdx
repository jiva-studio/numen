## Five things a tab can hold

| | |
| --- | --- |
| A note | the prose, [saving as you type](/writing/). |
| A plex | the map of what a note is connected to. |
| An agent | a conversation about the vault. |
| A document | a book or a PDF, [read where it stands](/documents/). |
| The files | [the folders of the vault](/files/) as they are on disk. |

A new tab asks what goes in it and lists those five. Every kind opens as many times as you like:
two notes side by side, two plexes standing at different notes, a second agent working on
something else.

## When nothing is open

Close the last tab and the window does not go blank: it draws the ways in, each with the key
that reaches it — search the vault, show the commands, a new note, a plex, an agent — and under
them the vaults this installation holds. The one you are in says so; one whose folder has gone
says that instead.

A window standing on no vault at all offers only that list, and **New vault**: a plex and an
agent each need a vault to stand on.

## Panes

Drag a tab to the edge of a pane to split it — left, right, top or bottom, whichever edge you
came closest to. Drag it into the middle of another pane to join that stack instead. The handle
between two panes moves the boundary.

**Open beside** in the commands does the same without the dragging: it puts what you chose in a
pane next to the one you are in.

<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>W</kbd> closes the tab in front of you. A tab
holding an unanswered question is told once, and closes the second time you ask.

## The two keys everything starts from

<kbd>Ctrl</kbd>/<kbd>⌘</kbd> <kbd>K</kbd> searches the vault. <kbd>Ctrl</kbd>/<kbd>⌘</kbd>
<kbd>P</kbd> opens the commands — everything the window can do, over the note you are on, over
the window, and over the vault. Both are in the same panel and each closes the other.

Commands are grouped by what they act on:

- **This note** — show it in the plex, make a child, change the title, ask the agent about it,
  copy its path, remove it.
- **This window** — a new note, a new agent, close this tab, search, appearance.
- **This vault** — go to a note, open or make a vault, rename, forget, erase.

A command that cannot act on what is in front of you says why rather than disappearing: with a
document open, *nothing in front of you is a note*; during the first scan, *the vault is still
being read*.

The [keyboard page](/keyboard/) lists what has a key of its own.

## The corner

The corner of the window shows what is running behind it: the first scan of a vault, a model
being fetched, a scanned document being read. Each entry can be put away when you have seen it.

It is also where the window says something is wrong with the vault as a whole — *not following
the vault*, *the vault could not be read*. See [when something is wrong](/trouble/).
