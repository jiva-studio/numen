# Vault Tools

Provides MCP tools for reading, searching, creating, and linking notes and sources inside the active vault.

<!-- more -->

## Tools Provided

- **Note & source search (`note_search`, `source_read`)**: Semantic and full-text search across notes, books, documents, and transcripts with passage offsets.
- **Note editing & creation**: Read, create, update, and link vault notes while preserving frontmatter and wikilinks.
- **Heading & link inspection**: Traverse document outlines and incoming/outgoing links across the vault graph.
