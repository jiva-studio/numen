# Vault Knowledge Tools

Allows AI assistants in Numen to search your library, read notes and books, create or update notes, and explore links between ideas.

<!-- more -->

## What It Enables

- **Smart library search**: Lets the assistant find relevant passages across your notes, books, PDFs, and transcripts—both by exact words and by meaning.
- **Reading and quoting sources**: Allows the assistant to open specific pages or timestamps so its answers include clickable links back to the original passage.
- **Creating and organizing notes**: Lets the assistant draft new notes, update existing ones, and connect related notes with links.
- **Exploring your knowledge graph**: Helps the assistant see which notes link to each other and discover isolated or unlinked notes.
