# OpenAI Codex Agent

Use the OpenAI Codex assistant (`codex`) installed on your computer to explore your vault, answer questions, and help write notes.

<!-- more -->

## What You Can Do

- **Chat with OpenAI models**: Use the models from your local Codex setup inside the Agent Chat panel.
- **Search and edit notes**: Let the assistant look up passages across your books and notes and suggest edits you can accept or reject.

## Settings

- **Executable path**: Select the `codex` program on your computer if it is not detected automatically.
